
# Task 1 — AI Bug Description Clarifier

## 1. Task Objective

Build a Python-based **AI Bug Description Clarifier** that converts an informal developer bug report into a clear, structured, and professional bug summary using an OpenAI-compatible Chat Completion API.

### Input

```text
App keeps crashing when I click save.
```

### Expected behavior

The AI should transform the informal description into a concise and professional bug description, for example:

```text
The application crashes when the user clicks the Save button.
```

> The exact AI response may vary because it is generated by the model.

The prompt should contain the developer's actual bug description.

Example:

```python
prompt = f"""

and professional bug summary. Include the issue and relevant observed

{description}

```

The important part is:

```python

```

This makes the prompt **dynamic/parameterized**.

### Example

# 9. Chat Completion API Call

The application calls:

```python
response = client.chat.completions.create(
    model="openai/gpt-4.1-mini",
    messages=[
        {
            "role": "user",
            "content": prompt
        }
    ],
    max_tokens=100,
    temperature=0.0
)
```

### Configuration

| Parameter     | Value                 | Purpose                            |
| ------------- | --------------------- | ---------------------------------- |
| `model`       | `openai/gpt-4.1-mini` | AI model                           |
| `messages`    | User + prompt         | Sends the instruction              |
| `max_tokens`  | `100`                 | Limits response length             |
| `temperature` | `0.0`                 | Produces more deterministic output |

# 11. Complete Python Code

For GitHub, your `bug_clarifier.py` can contain:

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ.get("OPENAI_API_KEY"),
    base_url=os.environ.get("OPENAI_API_BASE")
)


def clarify_bug(description: str) -> str:
    prompt = f"""
Rewrite the following informal bug report into a clear, structured,
and professional bug summary. Include the issue and relevant observed
behavior. Do not invent information that is not present in the report.

Bug report:
{description}
"""

    response = client.chat.completions.create(
        model="openai/gpt-4.1-mini",
        messages=[
            {
                "role": "user",
                "content": prompt
            }
        ],
        max_tokens=100,
        temperature=0.0
    )

    return response.choices[0].message.content


description = "App keeps crashing when I click save."

response = clarify_bug(description)

print(response)
```
